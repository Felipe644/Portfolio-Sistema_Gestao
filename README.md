# Sistema de Cadastro e Gestão de Tarefas

## 📋 Sobre o projeto

Projeto desenvolvido com o objetivo de demonstrar, de forma prática,
o ciclo completo de desenvolvimento de uma solução de software,
desde o levantamento de requisitos até os testes e a automação.

## 🎯 Objetivo

Desenvolver um sistema para cadastro e gestão de tarefas,
permitindo aos usuários criar, consultar, editar, acompanhar
e gerenciar suas atividades.

## 🔄 Ciclo do projeto

O projeto será desenvolvido seguindo as etapas:

1. Requisitos
2. Histórias de Usuário
3. Gherkin
4. Protótipo
5. UML / BPMN
6. API REST
7. Banco de Dados / SQL
8. Testes
9. Automação com Playwright
10. Git / GitHub

## 🛠️ Tecnologias

- Git
- GitHub
- Markdown
- API REST
- SQL
- Playwright
- TypeScript
- Node.js
