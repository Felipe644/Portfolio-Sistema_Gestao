# Regras de Negócio

## RB01 — Título obrigatório

Toda tarefa deve possuir um título.

## RB02 — Descrição obrigatória

Toda tarefa deve possuir uma descrição.

## RB03 — Responsável obrigatório

Toda tarefa deve possuir um responsável.

## RB04 — Prioridade obrigatória

Toda tarefa deve possuir uma prioridade.

## RB05 — Status inicial

Toda nova tarefa deve ser cadastrada com o status "A Fazer".

## RB06 — Responsável único

Cada tarefa deve possuir apenas um responsável.

## RB07 — Conclusão da tarefa

Uma tarefa somente poderá ser considerada concluída quando
estiver com o status "Concluída".

## RB08 — Prazo

A data de vencimento de uma tarefa não poderá ser anterior
à sua data de criação.

## RB09 — Tarefa atrasada

Uma tarefa cujo prazo tenha sido ultrapassado e que não esteja
concluída deverá ser identificada como atrasada.

## RB10 — Exclusão

O sistema deve solicitar confirmação do usuário antes de excluir
uma tarefa.
