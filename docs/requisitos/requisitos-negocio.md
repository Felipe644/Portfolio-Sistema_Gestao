# Requisitos de Negócio

## Objetivo

Definir as necessidades do negócio que serão atendidas pelo
Sistema de Cadastro e Gestão de Tarefas.

## RNG01 — Centralização do gerenciamento de tarefas

O sistema deve centralizar o cadastro e o gerenciamento das
tarefas em uma única aplicação.

## RNG02 — Acompanhamento das tarefas

O sistema deve permitir que os usuários acompanhem o andamento
das tarefas cadastradas.

## RNG03 — Controle de responsabilidades

O sistema deve permitir identificar o responsável por cada tarefa.

## RNG04 — Controle de prazos

O sistema deve permitir o acompanhamento dos prazos definidos
para as tarefas.

## RNG05 — Controle de prioridades

O sistema deve permitir a classificação das tarefas de acordo
com sua prioridade.
