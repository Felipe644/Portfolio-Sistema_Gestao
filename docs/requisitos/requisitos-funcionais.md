# Requisitos Funcionais

## RF01 — Cadastrar tarefa

O sistema deve permitir que o usuário cadastre uma nova tarefa.

## RF02 — Consultar tarefas

O sistema deve permitir que o usuário consulte as tarefas
cadastradas.

## RF03 — Editar tarefa

O sistema deve permitir que o usuário altere os dados de uma
tarefa cadastrada.

## RF04 — Alterar status da tarefa

O sistema deve permitir que o usuário altere o status de uma
tarefa.

## RF05 — Excluir tarefa

O sistema deve permitir que o usuário exclua uma tarefa cadastrada.

## RF06 — Filtrar tarefas

O sistema deve permitir que o usuário filtre as tarefas por
diferentes critérios.

## RF07 — Pesquisar tarefas

O sistema deve permitir que o usuário pesquise uma tarefa
pelo título.
