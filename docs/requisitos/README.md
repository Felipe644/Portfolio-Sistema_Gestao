# Requisitos — Sistema de Gestão de Tarefas

## 1. Objetivo

Documentar os requisitos necessários para o desenvolvimento do
Sistema de Cadastro e Gestão de Tarefas.

## 2. Objetivo do Sistema

O sistema tem como objetivo centralizar o cadastro, acompanhamento
e gerenciamento de tarefas, permitindo o controle de responsáveis,
prioridades, prazos e status.

## 3. Requisitos de Negócio

### RN01 — Centralização das tarefas

O sistema deve centralizar o gerenciamento das tarefas em uma
única aplicação.

### RN02 — Acompanhamento

O sistema deve permitir o acompanhamento do andamento das tarefas.

### RN03 — Controle

O sistema deve permitir o controle de responsáveis, prioridades,
prazos e status das tarefas.

## 4. Requisitos Funcionais

| ID | Requisito |
|---|---|
| RF01 | Cadastrar tarefa |
| RF02 | Consultar tarefas |
| RF03 | Editar tarefa |
| RF04 | Alterar status da tarefa |
| RF05 | Excluir tarefa |
| RF06 | Filtrar tarefas |
| RF07 | Pesquisar tarefas |

## 5. Requisitos Não Funcionais

### RNF01 — Segurança

O sistema deve permitir acesso somente a usuários autenticados.

### RNF02 — Usabilidade

O sistema deve apresentar mensagens claras e objetivas ao usuário.

### RNF03 — Performance

O sistema deve apresentar tempo de resposta adequado para as
operações realizadas pelo usuário.
