# Protótipo — HU01 Cadastrar Tarefa

## Objetivo

Representar visualmente a tela utilizada para o cadastro de uma nova tarefa.

## HU relacionada

[HU01 — Cadastrar Tarefa](../../historias-usuario/HU01-cadastrar-tarefa.md)

## Tela

![Protótipo da tela de cadastro](./PSM1.png)

## Campos

| Campo | Tipo | Obrigatório | Observação |
|---|---|---|---|
| Título | Texto | Sim | Nome da tarefa |
| Descrição | Texto | Sim | Detalhamento da tarefa |
| Responsável | Select | Sim | Usuário responsável |
| Prioridade | Select | Sim | Baixa, Média ou Alta |
| Status | Select | Não | Inicia como "A Fazer" |

## Ações

- **Cadastrar:** realiza o cadastro da tarefa.
- **Cancelar:** cancela a operação.
